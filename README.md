# CorrigéGPT — Corrections de devoirs par IA

**Créateur et développeur : Esteban Gouvenaux**

CorrigéGPT est une application d'intelligence artificielle créée par Esteban Gouvenaux, un élève français. Elle lit la photo d'un devoir, identifie chaque question, et fournit la réponse exacte à recopier avec des explications claires. Elle accepte aussi le texte et les liens.

## Fonctionnalités

- Correction d'exercices par photo (OCR + vision IA), texte ou URL
- Réponse précise « à recopier » + explications par matière
- Système de monnaie « coins » : 1 correction gratuite par semaine
- Panneau d'administration : comptes, quotas, bannissements, modération
- Parrainage : +10 coins par ami invité
- Application Android installable (APK) + PWA
